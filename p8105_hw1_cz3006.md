The mean is calculated for the random sample as well as the logical
vector. Since the random sample is numerical, its mean can be
calculated. The logical vector also has a mean, since R changes TRUE to
1 and FALSE to 0. The character and factor vectors result in NA, because
mean can only be calculated on numerical and logical vectors.

``` r
as.numeric(pull(problem2_df, logical_vector))
as.numeric(pull(problem2_df, character_vector))
as.numeric(pull(problem2_df, factor_vector))
```

Applying as.numeric() to logical vectors changes FALSE to 0 and TRUE
to 1. When applied to character vectors, as.numeric() returns a value of
NA. This is because the letters are not convertible to numbers. When
applied to factor vectors, as.numeric() returns the numeric
representation of the factor levels. This means, that for a factor
vector with levels A, B, and C, as.numeric() would return 1, 2, and 3
respectively. This helps explain the results above: logical vectors can
have a mean because they can be treated as 0s and 1s, while character
and factor vectors do not have a meaningful mean directly.
